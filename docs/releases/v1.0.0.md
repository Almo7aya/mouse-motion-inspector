# Mouse Motion Inspector 1.0.0

The first public release of a Windows utility for investigating unexpected mouse
movement and identifying the Windows input interface that reported it.

## Download and run

- **Windows x64, self-contained ZIP:** includes .NET. Extract the entire ZIP and
  launch `MouseMotionInspector.exe` as a normal user. Choose this package if you
  do not already have the .NET 10 Windows Desktop Runtime installed.
- **Windows x64, framework-dependent ZIP:** install the
  [.NET 10 Windows Desktop Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/10.0),
  extract the entire ZIP, and launch `MouseMotionInspector.exe` as a normal user.
  Keep its companion files together.
- **Source ZIP:** build on Windows with the .NET 10 SDK using `build-native.ps1`.
- Every attached ZIP includes a separate SHA-256 checksum file. Compare it with
  `Get-FileHash <downloaded-file.zip> -Algorithm SHA256`.

## Included

- Windows Raw Input device attribution, separate injected-event monitoring and
  cursor observations.
- Timed hands-off tests with settling time and editable DPI/polling presets.
- Movement path, displacement and activity graphs, pan/zoom, and PNG exports.
- Incremental graph preparation and a display scheduler targeting roughly
  60 updates per second; capture retains full observations.
- JSON recording/reopening, CSV summaries and a standalone browser companion.
- A visual four-step interpretation guide, illustrative movement patterns and
  troubleshooting by topic.
- An About tab with version, MIT license, credits, privacy information and links.

## Validation and limits

Validation passed: 32 native data-handling checks and 16 browser checks, plus
off-screen chart/guide/About rendering. These do not establish physical-device
accuracy, displayed frame rate, every display-scaling configuration or
clean-machine installation. See the [release checklist](https://github.com/Almo7aya/mouse-motion-inspector/blob/v1.0.0/docs/release-checklist.md).

Raw Input identifies Windows interfaces; it does not prove a sensor fault or
identify the process responsible for every cursor change. DPI/polling entries
are labels, not device controls or measurements. Packages are unsigned.

Recordings stay local and may contain device identifiers, coordinates and notes.
Review them before sharing. The app does not record keystrokes or upload captures.
GitHub Actions runs only through a manual workflow dispatch. MIT licensed.
